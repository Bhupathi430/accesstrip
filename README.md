ABOUT THE APPLICATION
---------------------
Access Trip is an all-in-one inclusive travel guide web platform engineered
to provide barrier-free mobility and accessibility guidance for travelers across
Andhra Pradesh, Telangana, and major Indian metropolitan destinations.

Key Features & Sequential 6-Step Workflow:
-----------------------------------------
1. Step 1 - Traveler Profile Selection:
   Customize filters for Wheelchair Users, Elderly / Senior Citizens,
   Visually Impaired travelers, Families with Baby (strollers/nursing),
   and Needs Quiet Environment (low sensory).

2. Step 2 - Destination Cities Selection:
   Select Outgoing City (Origin) and Incoming Destination across Andhra Pradesh,
   Telangana, Karnataka, Tamil Nadu, Kerala, Maharashtra, Delhi NCR, Goa, etc.

3. Step 3 - Recommended Hotels & Prices in Rupees (₹):
   View hotel recommendations with rates in INR (₹) and accessibility audits
   (Ramps, Roll-In Showers, Elevators, Trained Staff).

4. Step 4 - Ranked Stays Leaderboard:
   Inspect stays ranked #1 Gold, #2 Silver, #3 Bronze based on overall accessibility
   score out of 100 and value.

5. Step 5 - Real Tourist Places Guide:
   Discover real attractions with 5-star accessibility ratings, entry fees in ₹,
   audio guide availability, baby care rooms, and practical tips.

6. Step 6 - Route Safety Analyzer:
   Compare Long Accessible Route (Safer Choice with rest plazas) vs Short Route
   (High Risk / Dangerous Terrain with steep slopes) featuring an interactive
   SVG map visualizer.


HOW TO RUN AND DEPLOY
---------------------

1. INSTANT SINGLE-FILE DEPLOYMENT (No Installation Required):
   Simply double-click the included single-file HTML document:
   "Access_Trip_Single_File.html"
   It opens instantly in Google Chrome, Microsoft Edge, Mozilla Firefox, or Safari.

2. FOR DEVELOPERS (Source Build):
   - Install dependencies: npm install
   - Run local development server: npm run dev
   - Build single-file production bundle: npm run build
